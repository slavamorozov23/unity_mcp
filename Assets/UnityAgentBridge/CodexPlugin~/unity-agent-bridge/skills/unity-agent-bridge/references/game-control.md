# Кадры Unity

## Сцена

`scene_screenshot` принимает `query` и `mode`. `flat` приближает лучший результат. `grid` для 3D возвращает четыре ракурса, для 2D — до четырёх найденных объектов крупным планом.

## Игра

Первый `Start Server` предлагает установить Input System и включает режим `Both`. `game_actions` передаёт события через виртуальные устройства Input System. Код на `UnityEngine.Input` и callbacks `OnMouse...` этот ввод не получит. uGUI со старым `StandaloneInputModule` на время игры переводится на `InputSystemUIInputModule` без изменения сцены.

Если `game_actions` запускает игру, Bridge ждёт Play Mode `ready` и готовый кадр. Пустой `actions` даёт начальный кадр. Между пакетами игра стоит на паузе.

`wait` пропускает указанное игровое время с временным ускорением `Time.timeScale` в 10 раз.

`x/y` относятся к последнему кадру. Кадр без растяжения вписывается в `1280×720` или `720×1280`. По умолчанию `button=left`, у `drag` `duration=0.5`, у `press_key` `duration=0.15`. У `scroll` отрицательные `scrollX/scrollY` ведут влево/вверх, положительные — вправо/вниз. Поддержаны обычные клавиши Windows и сочетания через `+`. Ввод идёт внутри Unity; системные курсор, клавиатура и фокус окна не используются.

Дерево и логи запрашивать только по отдельной причине.

## Sprite

`sprite_editor` возвращает размеченную текстуру. `auto` нарезает Multiple автоматически, `manual` принимает точные прямоугольники, `border` задаёт границы Single; `preview` ничего не меняет.

Этот режим не годится для проверки анимаций и объектов, которые непрерывно движутся или меняются на экране: агент видит только кадр после пакета.
